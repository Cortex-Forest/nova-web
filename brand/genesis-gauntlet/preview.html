5 · Notes

· Not game UI: single easing family (ease-in-out, no bounce), 0.57s node cadence, no HUD, no counters, no sound.

· Reduced motion: the particle layer is CSS and is switched off under prefers-reduced-motion. For a full opt-out, render gauntlet-static.svg instead of the animated file.

· Loop: every SMIL animation is dur="18s" repeatCount="indefinite", so the whole build stays in sync and returns to the particle state.
